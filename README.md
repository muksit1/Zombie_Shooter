# Zombie Shooter Starter

This project is built with pure `C++` and the Windows `Win32 API`, so you do not need any extra game library.

## Run

1. Run `build.bat`
2. Run `zombie_game.exe`

## Controls

- `Enter`: start from menu
- `WASD` or arrow keys: move
- Mouse: aim
- Left click or `Space`: shoot
- `1`, `2`, `3`, `4`: switch guns
- `R`: reload during gameplay
- `P`: pause or resume
- `R`: restart after game over
- `Esc`: return to menu from game over

## Features

- start menu
- wave system
- boss wave every 5th round
- pistol, AK-47, M4 rifle, and shotgun
- sprite-style player, zombie, boss, and bullet graphics
- score and saved high score
- player health display
- ammo, reserve ammo, and reload system
- pause screen
- game over screen
- zombie difficulty increases each wave
